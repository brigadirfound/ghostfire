# Что загружать в консоль

## Архив

- `ghostfire_yandex.zip` в корне проекта — поле «Архив». Собирается `npm run pack`
  только на чистом worktree; рядом лежат `.sha256` и `.manifest.json` для сверки.

## Иконка и обложки

- `visuals/icon-512.png` — поле «Иконка».
- `visuals/icon-maskable-512.png` — поле «Maskable иконка».
- `visuals/cover-800x470.png` — поле «Обложка».
- `visuals/hero-1560x520.png` — поле «Обложка на витрину».

## Скриншоты

- `screenshots/ru/desktop/` — русский десктопный набор 1920×1080.
- `screenshots/ru/mobile/` — русский мобильный набор 1080×1920.
- `screenshots/en/desktop/` — английский десктопный набор 1920×1080.
- `screenshots/en/mobile/` — английский мобильный набор 1080×1920.

Загружайте три кадра из соответствующей папки. Для каждой выбранной платформы
требуется минимум два кадра. Десктопные материалы отмечаются как альбомные,
мобильные как портретные.

## Тексты

- `submission/listing-ru.md` — русский черновик.
- `submission/listing-en.md` — английский черновик.

Комментарий для модерации в конце каждого листинга вставляется в поле
«Комментарий разработчику».

## После создания черновика

ID игры из URL страницы в каталоге вписать в `js/config.js` → `yandexAppId`,
затем **пересобрать архив**: без ID вызов другу делится кодом, с ID — ссылкой
с автоподстановкой призрака.
