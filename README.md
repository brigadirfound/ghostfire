# 👻 GHOSTFIRE

Браузерный воксельный FPS: дуэль 1v1 против **призрака** — записи реального игрока,
которая повторяет его движение, но целится в тебя живьём. Убей призрака быстрее,
чем его хозяин убивал своих противников. Побей — запишется твой призрак, отправь
его другу одной ссылкой.

**Играть:** https://brigadirfound.github.io/ghostfire/
**Редактор карт и скинов:** https://brigadirfound.github.io/ghostfire/editor.html

Полностью автономно: Three.js self-host (без CDN, `vendor/`), вся геометрия
карт и текстуры блоков — кодом, звук — синтез Web Audio. Источники и доступные
лицензионные сведения по 3D-моделям и библиотекам перечислены в [NOTICE.md](NOTICE.md).
Один статик-хостинг, деплой через GitHub Actions после полного набора проверок.

```bash
npx http-server -p 8123 -c-1 .
# открыть http://localhost:8123
```

Регенерация контента и сборка билда — см. [PROJECT.md](PROJECT.md#запуск).

## Проверки и релизный пакет

Нужен Node.js 22+. Внешних npm-зависимостей у проверок нет.

```bash
npm test                         # syntax, JSON/glTF, карты, пикапы, replay, unit
node tools/sim_economy.mjs       # экономика: минуты игры до первого скина
node tools/stage_runtime.mjs out # тот же runtime-whitelist, что использует Pages
npm run pack                     # только на чистом worktree
```

Пакет содержит `release-manifest.json` с версией, commit и SHA-256 каждого
runtime-файла; рядом создаются `.sha256` и `.manifest.json`. Для осознанной
диагностической сборки незакоммиченного состояния есть `--allow-dirty`.

## Управление

| | Десктоп | Мобилка |
|---|---|---|
| Движение | WASD | левая половина — виртуальный стик |
| Камера | мышь (pointer lock) | правая половина — свайп |
| Огонь | ЛКМ (рейлган: клик → зарядка 0.8с) | кнопка FIRE или автоогонь (в настройках) |
| Прыжок | Space | кнопка JMP |
| Пауза | Esc | кнопка Ⅱ |

```

js/player.js  js/ghost.js     — контроллер (+ кисть от первого лица) и призрак

js/map.js  js/textures.js        — карта из JSON, процедурный атлас текстур блоков
js/economy.js                     — награды за матч, госткоины
js/mobile.js  js/ui.js             — тач-управление, экраны
js/face.js  js/skin-editor.js  js/editor.js  js/botgen.js  js/mappreview.js — UGC
js/platform.js                      — ЕДИНСТВЕННАЯ точка контакта с платформой (Яндекс SDK/заглушки)
js/config.js  js/audio.js  js/i18n.js — конфиг, синтез звука, строки ru/en
maps/ skins/ ghosts/ assets/            — контент (JSON, GLTF, JPG)
vendor/                                  — self-host three.js
tools/                                    — seed-генераторы, валидаторы, общий whitelist и воспроизводимый ZIP
```

Подробности архитектуры (формат записи призрака, формат карты, параметры
оружия/движения, скайбокс, известные проблемы, план V2) — в [PROJECT.md](PROJECT.md).
