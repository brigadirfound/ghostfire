# 👻 GHOSTFIRE

Браузерный воксельный FPS: дуэль 1v1 против **призрака** — записи реального игрока,
которая повторяет его движение, но целится в тебя живьём. Убей призрака быстрее,
чем его хозяин убивал своих противников. Побей — запишется твой призрак, отправь
его другу одной ссылкой.

**Играть:** https://brigadirfound.github.io/ghostfire/
**Редактор карт и скинов:** https://brigadirfound.github.io/ghostfire/editor.html

Без сборщиков и внешних ассетов: Three.js с CDN, вся геометрия — кодом,
звук — синтез Web Audio, текстуры масок — CanvasTexture. Один статик-хостинг.

## Что уже работает

### Ядро
- ✅ FPS-контроллер: WASD + мышь, прыжки, стрейф без инерции, распрыжка
- ✅ 3 пушки: пистолет (бесконечный), дробовик и рейлган — подбор на карте, респаун 10с
- ✅ Hitscan с зонами урона: голова ×2 (головы кубов большие — это фишка)
- ✅ Призрак: движение точно по записи (20 снапшотов/с), прицеливание живое —
  с профилем меткости оригинала и реакцией 150–300 мс
- ✅ Матч до 5 побед, смерть = сочный разлёт на кубики
- ✅ 5 встроенных ботов нарастающей сложности (не проходят сквозь стены)
- ✅ Шеринг призраков: код/ссылка (LZ-string), с пользовательской карты призрак
  уезжает вместе с картой
- ✅ Звук полностью синтезом (выстрелы, попадания, отсчёт, фанфары)

### Контент и UGC
- ✅ Редактор карт: блоки по граням, спавны, точки оружия, импорт/экспорт кода,
  «Своя карта» в игре + боты, синтезируемые под неё
- ✅ Редактор скинов: цвета тела/пушек/трассеров + живое 3D-превью
- ✅ Пиксель-арт кастомизация: рисовалка 16×16 (лицо и одежда), 6 готовых масок,
  загрузка своей картинки → пиксель-арт на лицо
- ✅ 3D-модели оружия из примитивов (PBR-металл, свечение рейлгана) —
  контраст с воксельным миром; скин может заменить модель воксельной

### Платформа и деньги
- ✅ Мобильное управление: стик, свайп камеры, кнопка огня / автоогонь,
  aim-assist 3°, пинч-зум заглушен
- ✅ Экономика: госткоины (стартовый бонус 100), магазин с 5 скинами,
  паки коинов за Яны (Яны → коины только в одну сторону)
- ✅ Яндекс SDK интегрирован с автоопределением окружения: реклама, облачные
  сейвы, лидерборд, покупки с consume; локально — заглушки
- ✅ Деплой на GitHub Pages через Actions на каждый push
- ✅ Сборка билда для Яндекса: `powershell -File tools/pack_yandex.ps1`

## Что НЕ доделано (кандидаты на следующий спринт)

- ⬜ **Обкатка мобилки на реальном таче** — стик/свайп/автоогонь живьём не проверены
- ⬜ **Экран загрузки** — сейчас чёрный экран, пока грузится Three.js с CDN
  (Яндекс это не любит; надо прелоадер + возможно self-host three.js)
- ⬜ **Туториал/онбординг** — никто не объясняет подбор пушек, распрыжку и суть призрака
- ⬜ **Баланс ботов** — сложности не выверены по ощущениям реальных игроков
- ⬜ **Магазин голый** — нет 3D-превью скина в карточке, маски не продаются отдельным
  слотом (а это самый дешёвый контент)
- ⬜ **Звук при рекламе** — interstitial не глушит игру
- ⬜ **Товары в консоли Яндекса** — завести pack_s/pack_m/pack_l и лидерборд `wins`
- ⬜ **UGC-витрина** — публикация карт/скинов в общий каталог, процент автору
  в госткоинах (нужен простенький бэкенд)
- ⬜ **Живой PvP** — Colyseus-сервер; протокол снапшотов уже готов ехать по WebSocket
- ⬜ Килфид, статистика по зонам, сезонные маски за достижения

## Запуск локально

```bash
npx http-server -p 8123 -c-1 .
# открыть http://localhost:8123
```

Регенерация контента:

```bash
node tools/gen_maps.mjs     # карты maps/*.json
node tools/gen_ghosts.mjs   # встроенные боты ghosts/*.json
```

## Управление

| | Десктоп | Мобилка |
|---|---|---|
| Движение | WASD | левая половина — виртуальный стик |
| Камера | мышь (pointer lock) | правая половина — свайп |
| Огонь | ЛКМ (рейлган: клик → зарядка 0.8с) | кнопка FIRE или автоогонь (в настройках) |
| Прыжок | Space | кнопка JMP |
| Пауза | Esc | — |
